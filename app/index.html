How it works

      
Everything here is invented and runs in your browser. Nothing is sent anywhere.

      
The model

      
1,600 synthetic past applicants to an invented graduate scheme, each with six features. Past shortlisting decisions came from a hidden rule plus noise, with a fixed quota of 38% shortlisted. A small gradient-boosted model (60 trees, each two splits deep) learns to copy those decisions. A score of 0.50 or more means "shortlist".

      
Counterfactual routes

      
A counterfactual explanation answers "what would have had to be different for the answer to be yes?". Here it is restricted to changes a person could actually make: features can only move in a realistic direction (more experience, never less), by a limited amount, and degree result and past gaps are fixed unless you say otherwise.

      
Because the model is a sum of trees, its score only changes where a tree splits. So for each feature the tool only needs the current value and the first value past each split point. It searches those combinations cheapest first and stops at the first one that reaches the target (0.50 plus any safety margin), which makes the result the exact cheapest plan, not an approximation. Before searching, it adds up the best leaf each tree could reach within the allowed changes; if even that falls short of the target, there is no route and no search is needed.

      
Effort

      
Effort is the percentile shift each change needs among past applicants, times an effort weight you choose. Moving from a common value to a rare one costs more than the same number of units in a crowded range.

      
Why the model scored them this way

      
Shapley values split the gap between the average score and this applicant's score fairly between the six features, by averaging over every one of the 64 combinations of "this applicant's value" and "a reference applicant's value" (the code reaches the same exact answer tree by tree, which is much faster). They explain the score, but they do not say what to change: the feature that hurts most is often one nobody can change.

      
Will it hold?

      
The cheapest route lands just over the line by design, so it is fragile. The tool trains next year's model on 1,600 new applicants (optionally stronger on average, with the same quota, so the bar rises) and checks whether each route still reaches 0.50. A safety margin asks routes to aim higher, at the cost of more effort. One search answers every margin at once: the order in which the search visits plans does not depend on the target, so it simply notes the first plan that clears each margin.
