Page 1

The season

One season of an invented club, day by day: training, matches, knocks and strains. The warning light reads every player's recent workload each Thursday, and the coach acts on it as set on the clipboard.

Page 2

The warning light

How well does each light pick out the players about to pick up a soft-tissue injury? Thirty seasons are played with nobody acting on any flag, so every light is scored against the same injuries, alongside a perfect-knowledge ceiling that knows the hidden truth but not the luck.

Page 3

The pilot season

The club plays one normal season, then pilots the light the next and compares injury counts. Different seasons have different luck, which the pilot cannot see. The simulation can: it also replays each season with and without the light, on exactly the same luck.

Page 4

Squad policies

Five ways to manage the squad, each played over the same seasons with the same luck, so the differences are the policy and nothing else. Fewer injuries is not the same as more wins.

Page 5

The trade-off

Every way the club could use its light, at every flag level, plus rotation and picking on readiness, each played over the same seasons. Fewer days lost costs league points, so the right choice depends on one question only the club can answer: how many player-days of injury is a league point worth?

Page 6

The hidden truth

Every page so far rests on one version of the truth. How much load spikes really cause injury is still argued over, and no club can see it. So would the verdict survive if the truth were different? Each assumption is pushed low and high, one at a time, over the same seasons, and the light is scored again: how accurate it is, and what acting on it is worth.

Page 7

Your logbook

Bring a club's own session log (date, player, minutes and effort, with injuries if you have them). The app works out every player's workload ratios, this week's flags and, if injuries are recorded, whether the ratios anticipated them better than chance. Nothing leaves your browser.

How it works
