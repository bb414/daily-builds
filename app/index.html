How the model works

Each pilot has hidden true traits: the annual value it would deliver once live, how measurable that value is, how complex it is to integrate, how long it takes to show results, and what it costs to run each quarter. Roughly one idea in five is genuinely worth scaling under the default assumptions.

  • Every quarter, running pilots cost money. Once a pilot has had time to show results, it produces evidence, which understates its real value when benefits are hard to measure.
  • A pilot goes live only if a strategy and scaling owner exist, its evidence clears the bar, and the organisation has capacity that quarter. The strongest cases go first.
  • Without stop criteria, weak pilots drift until a sponsor gives up. With them, pilots that miss their evidence gate are stopped two quarters later.
  • Reused budget funds new pilots, except in the final year. A shared platform makes each go-live cheaper, down to half the original cost.
  • A stalled pilot is blamed on long timescales if it never produced evidence; hard-to-measure benefits if it was worth scaling but could not prove it; no route to scale if it could prove it but had no owner, capacity or sponsor; technical complexity if only its complexity made it uneconomic; and unclear ROI otherwise.

Every number is an illustrative assumption, not data from real organisations. Use the model to reason about mechanisms and trade-offs, not to forecast. The Python version in this repository produces the same results in distribution and has its own test suite.
