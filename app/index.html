How Range finder works

Each driver is a range you are 90% sure about, so there is a 5% chance the truth is below your low value and a 5% chance it is above your high value. Pick the kind of range that fits: skewed for positive quantities where twice the middle value is as likely as half of it (counts, prices, volumes), symmetric when errors either way are equally likely, percentage for shares between 0 and 100, even when any value between the two ends is equally likely (here low and high are hard limits), and known exactly for fixed numbers.

Range finder then draws 10,000 combinations (unless a model file asks for a different number) using Latin hypercube sampling (every slice of every range is used exactly once), works out the estimate for each, and summarises the results. Because each driver appears once and terms are only multiplied and added, it can also work out exactly how much of the spread each driver causes, and how much knowing each one would be worth before a decision.

Results

Every calculation happens in this page: nothing is sent anywhere. The examples are invented and their numbers are illustrative, not research. Results use Latin hypercube samples (10,000 unless a model file sets another number) with a fixed seed, so the same inputs always give the same answer.
